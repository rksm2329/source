## P6475 [NOI Online #2 入门组] 建设城市

### 题意

给定正整数 $m, n, x, y$，其中 $1 \le x \lt y \le 2n$。求满足以下条件的数列 $\{ A_{2n} \}$ 的数量：
- $\forall 1 \le i \le 2n, 1 \le A_i \le m$；
- $A_1 \le A_2 \le \dots \le A_n$，$A_{n + 1} \ge A_{n + 2} \ge \dots \ge A_{2n}$；
- $A_x = A_y$。

### 思路

先写出一个公式，在下面的引用中，都指的是此式中的变量。在 $N$ 个位置中选出 $K$ 个位置且可以重复选择的组合方案数为

$$
\binom {N + K - 1} K
$$

首先，$A_x$ 和 $A_y$ 相等，可以考虑枚举这两个数。设我们当前枚举 $A_x = A_y = h$，分类讨论：
1. $1 \le x \lt y \le n$。此时相当于 $A_x$ 到 $A_y$ 的所有数都 $= h$：
  - 对于 $A_1$ 到 $A_{x - 1}$，$N = h, K = x - 1$；
  - 对于 $A_{y + 1}$ 到 $A_n$，$N = m - h + 1, K = n - y$；
  - 对于 $A_{n + 1}$ 到 $A_{2n}$，$N = m, K = n$。
2. $1 \le x \le n \lt y \le 2n$：
  - 对于 $A_1$ 到 $A_{x - 1}$，$N = h, K = x - 1$；
  - 对于 $A_{x + 1}$ 到 $A_n$，$N = m - h + 1, K = n - x$；
  - 对于 $A_{n + 1}$ 到 $A_{y - 1}$，$N = m - h + 1, K = y - n - 1$；
  - 对于 $A_{y + 1}$ 到 $A_{2n}$，$N = h, K = 2n - y$。
3. $n \lt x \lt y \le 2n$。此时相当于 $A_x$ 到 $A_y$ 的所有数都 $= h$：
  - 对于 $A_1$ 到 $A_n$，$N = m, K = n$；
  - 对于 $A_{n + 1}$ 到 $A_{x - 1}$，$N = m - h + 1, K = x - n - 1$；
  - 对于 $A_{y + 1}$ 到 $A_{2n}$，$N = h, K = 2n - y$

对于每种情况，将按照上面给出的 $N$ 和 $K$ 值代入开头提到的公式，相乘即得答案。
